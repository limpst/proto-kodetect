## 0. 한 문단 요약

Compact 명세(QuickGuide 5단계 · 테스트계획 6작업)는 **전부 구현**했습니다.
PRO 명세와 대조하면 **12항목 중 6개 충족, 3개 부분, 3개 미구현**입니다.
가장 큰 격차는 **탐지 유형(1/4)** 과 **대용량 처리 속도**이며, 둘 다 검출
엔진을 학습 모델로 교체해야 닫힙니다. 반대로 PRO가 1번 강점으로 내세우는
**폐쇄망 구동**은 오늘 CDN 의존을 걷어내 확보했습니다.

### 오늘 닫은 격차 — 폐쇄망 구동

PRO 제안서의 1번 강점은 *"인터넷 연결 불필요 — 외부 해킹 원천 차단"* 입니다.
그런데 우리 화면은 `cdn.jsdelivr.net` 에서 차트·3D 라이브러리를 받고 있었습니다.
**폐쇄망에 설치하는 순간 차트와 3D 뷰가 통째로 죽는** 구조였습니다.

두 파일(합 794KB)을 `frontend/static/vendor/` 로 옮겨 외부 요청을 0으로 만들었습니다.
검증: 페이지의 외부 `src` **0건**, 로컬 자산 17개 전부 200.

## 3. 구독 인증 — 사업 모델은 이미 정해져 있습니다

미구현 사유를 "사업 모델 결정 선행"이라고 적었는데, **PRO 자료에 가격이 명시**되어
있습니다(p14).

| 플랜 | 가격 (VAT 별도) |
|---|---|
| 월 구독 | 1,580,000 KRW / 월 |
| 연 구독 | 18,960,000 KRW / 연 (12+1 프로모션) |

포함 범위: AI 탐지 · 자동 정합 · 시계열 분석 · 기술 지원 업데이트.

즉 **결정할 것이 남아 있지 않고, 구현만 남았습니다.** 다만 폐쇄망 제품이므로
온라인 과금 서버를 전제할 수 없습니다. 설계는 이래야 합니다.

- **오프라인 라이선스 키** — 기관·만료일·기능범위를 담아 서명(Ed25519)한 키 파일.
  설치 시 넣으면 인터넷 없이 검증된다
- **기능 게이팅** — 만료 시 AI 분석만 잠그고 **조회·보고서 재출력은 남긴다.**
  이미 만든 판정서를 열지 못하게 하는 것은 안전 자료의 접근을 끊는 일이다
- **만료 전 경고** — 30·7·1일 전 화면 상단 고지

## 4. 실행 계획

### 1순위 — 검출 엔진 교체 (격차 1·2·3을 한 번에)

지금은 고전 영상처리 베이스라인입니다. 재현율 0.605, 폭 MAE 0.230mm,
균열 단일 유형. **학습 모델로 바꾸지 않으면 세 격차 모두 닫히지 않습니다.**

`CrackDetector.detect()` 인터페이스는 교체를 전제로 고정해 두었으므로 상위
계층은 수정이 필요 없습니다.

- 합성 데이터 생성기가 이미 7종 결함을 그립니다 → 세그멘테이션 학습셋 확보 가능
- 실촬영 라벨링 데이터가 필요합니다. 이것이 없으면 합성-실사 도메인 격차가 남습니다
- 대용량 속도는 타일 분할 + 배치 추론으로 해결합니다

### 2순위 — 시계열 자동 매칭 (격차 10)

PRO의 핵심 서사가 *"작년의 미세 균열이 성장했는지"* 인데, 지금은 사람이
`CrackTrack` 을 손으로 이어야 합니다. 정합(stitching)이 만든 공통 평면 좌표계
위에서 **회차 간 균열을 자동으로 잇는 것**이 다음 단계입니다. 정합이 이미
구현돼 있으므로 좌표 변환만 연결하면 됩니다.

### 3순위 — 운영 요건 (격차 6·7·12 + 구독)

- Smart Filtering: 검출 브라우저에 유형·크기·등급 필터 추가 (반나절)
- Focus Mode: 결과 뷰어에 단일 결함 집중 모드 (반나절)
- RBAC: 관리자/점검원/열람자 3역할 + 기관 분리 (2~3일)
- 오프라인 라이선스: 서명 키 검증 + 기능 게이팅 (2~3일)

### 4순위 — 1,000장 규모 정합 검증 (격차 4)

구현은 있으나 규모 검증이 없습니다. PRO 문제 정의가 *1,366장 / 39.8GB* 이므로
그 규모로 돌려 메모리·시간을 실측해야 "된다"고 말할 수 있습니다.

## 5. 남은 위험

| 위험 | 내용 |
|---|---|
| **합성-실사 격차** | 모든 벤치마크가 합성 표본 기준입니다. 실촬영 분포에서 성능이 떨어질 수 있습니다 |
| **PSF 보정계수** | 2.6px는 합성으로 맞춘 값입니다. 실제 카메라·렌즈에서 재보정이 필요합니다 |
| **계측 데이터** | 전부 시뮬레이션입니다. 실계측기 연동 시 어댑터 뒤로 옮겨야 합니다 |
| **RL 환경 파라미터** | 열화 전이확률·보수비용은 가정치입니다. 실제 유지관리 이력으로 재추정해야 정책이 의미를 갖습니다 |
| **배포 인증** | 공개 URL이 `admin/admin` 입니다. 강한 비밀번호로 즉시 교체해야 합니다 |
