## p4 · 제품 개요

**KO-DETECT PRO: 이미지 기반 AI 시설물 손상정보 검출·분석 솔루션**

| 축 | 내용 |

## p6 · 이미지 자동 정합

**이미지 자동 정합(Stitching): 수작업 대비 50% 시간 단축**

BEFORE (수작업) → AFTER (자동 정합)

- **GSD 및 중복도 기반 자동 스케일링**
- **1,000장 이상의 대용량 이미지 자동 정렬**
- 수작업 왜곡 및 오류 제거

## p8 · 프로세스 전환

**업무 프로세스의 완벽한 디지털 전환**

| | 흐름 |
|---|---|
| **AS-IS** | 드론 촬영 → 수동 다운로드 → ⚠️ **육안 검수(Subjective)** → 엑셀/CAD 수기 입력 → 종이 보고서 |
| **TO-BE** | 드론 촬영 → KO-DETECT PRO 가져오기 → **AI 자동 탐지/정합** → 보고서 자동 생성 → **디지털 DB 구축** |

AS-IS 는 중간에 **Disconnect**, TO-BE 는 **Automation**.

## p10 · 보안

**강력한 보안: 외부 유출 없는 로컬(On-Premise) 환경**

- **인터넷 연결 불필요 (No Internet Needed)** — 외부 해킹 원천 차단
- **데이터 주권 확보** — 모든 이미지와 보고서는 내부 서버/로컬 디스크에만 저장
- **기관별 맞춤 설정** — 보안 프로토콜에 따른 접근 권한 관리
