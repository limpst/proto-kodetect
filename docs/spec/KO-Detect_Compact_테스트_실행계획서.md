KO-Detect Compact 테스트 실행계획서
1단계 — 사전준비 (현장 가기 전, 사무실)
현장에 가기 전에 이것부터 확정합니다. 준비가 부실하면 사진·위치 데이터가 어긋나 AI 분석 입력이 망가집니다.
이것부터 하세요
☐ 조사 구역 1개를 정합니다. 권장: 1개 층 또는 1~2개 실, 부재 10~20개 규모.
☐ 대상 건축물 평면도(평면도·구조도)를 출력하거나 디지털로 확보합니다.
☐ 부재 식별 체계를 통일합니다. 층 / 실(室) / 부재번호 규칙 (예: 기둥 C1, 보 G1, 슬래브 S1).
☐ 장비를 점검합니다: 스마트폰, 크랙스케일(균열게이지), 줄자/레이저거리계, 손전등, 야장·필기구.
☐ ★ 스마트폰 카메라 설정을 통일합니다 — 동일 해상도, 위치·시각 메타데이터(EXIF) 기록 ON.
☐ ★ 사진 파일명 규칙을 정합니다: 층_실_부재_일련번호_컷종류  (예: 3F_S2_C3_001_scale.jpg).
☐ ★ 단계별 소요시간 기록표(별첨 A)를 준비합니다 — 단계 전환 때 즉시 기록할 수 있게 손 닿는 곳에.
☐  ★ KO-Detect Compact 구독 인증 상태를 미리 확인합니다 (AI 분석은 구독 인증이 완료돼야 사용 가능
— 설정 › 구독 정보).
다음 단계로 가기 전 확인:  구역·도면·장비·카메라 설정·파일명 규칙·시간기록표가 모두 준비됐다면
현장으로 출발합니다.

2단계 — 현장 데이터 수집 (건축물 현장)
기존 육안조사 방식 그대로 수행하되, KO-Detect에 입력할 수 있게 사진·위치를 규격에 맞춰 남깁니다.
순서대로 진행하세요.
① 진입 · 동선 설정
1. 조사 구역에 진입하고 안전을 확보합니다 (조명·환기·낙하물 확인).
2. 도면 그리드 기준으로 조사 순서(동선)를 확정합니다 — 누락·중복 방지.
3. 조사 시작 시각을 기록합니다.  ★ 시간기록표에 즉시 기입
② 부재별 육안조사 → 결함 탐지
4. 부재 단위(기둥 → 보 → 슬래브 → 벽체 순)로 표면을 육안 관찰합니다.
5. 결함 발견 시 유형을 판정합니다: 균열 / 박리·박락 / 철근노출 / 누수·백태 / 기타.
6. 균열은 크랙스케일로 폭(mm)을, 줄자로 길이·연장 방향을 측정합니다.
7. 결함의 진행성(건성/습윤, 누수 동반 여부)을 함께 관찰합니다.
③ 위치정보 기입 · 일련번호 부여
8. 결함을 도면(외관조사망도)에 표기하고, 위치를 기록합니다: 층 → 실 → 부재번호 → 부재 내 상세위치 (예:
C3 기둥 하단부 북측면, 바닥+0.5m).
9. 결함 일련번호를 부여합니다 (예: 3F-S2-C3-001). 별첨 B 위치정보 매칭표에 기록.
④ 사진 촬영
10. 결함별로 3종을 촬영합니다:  ① 위치 식별용 전경 1컷,  ② 결함 근접 1~2컷,  ③ 크랙스케일·줄자를 결함
옆에 댄 스케일 동반 컷
☐ ★ 스케일 동반 컷은 필수 — AI가 균열 폭을 추정·검증하는 기준입니다.
☐ ★ 흔들림·역광·초점 흐림 컷은 그 자리에서 재촬영 (동일 사진을 AI에 입력하므로).
☐ ★ 결함 일련번호 ↔ 사진번호 ↔ 위치정보를 1:1로 매칭해 현장에서 확정합니다.
⑤ 야장 정리 · 종료
11. 결함별로 [일련번호 / 위치 / 유형 / 규모(폭·길이·면적) / 사진번호 / 비고]를 야장에 기록합니다.

– ‘정보 부족’ 사진은 [치수 측정]으로 길이 기준(측정자)을 잡아야 분석됩니다.
– 비뚤게 찍힌 사진은 [사진 보정](4점 원근) 후 [다시 사진 분석하기]. 주의: 재분석하면 직접 고친
손상은 사라집니다.
19. (선택) 도면 배치 — 외관조사망도용 — [사진·도면 관리] → 도면 탭 → [+ 도면 추가]
(PDF·DXF·JPG·PNG, 도면 없으면 빈 화면으로 시작) → 도면을 열고 사진 그룹을 도면 위로 끌어 [위치]
생성 → 위치 핀에 부재·방향·메모 입력.
★ 시간 기록:  사진 등록 / 그룹 분류 / AI 분석 / 결과 검토·보정 / 도면 배치 각 작업의 소요시간을 별첨 A
