입력 항목 설명

사진 등록
1. 홈의 사진 확인하기 또는 상단 사진·도면 관리 메뉴 → 사진 탭으로 이동합니다.
2. 가운데 영역에 사진을 끌어다 놓거나 + 사진 추가 버튼을 누릅니다.
3. 파일 선택 창에서 사진을 고르면 자동 등록되고, 확인을 누르면 사진 목록에 채워집니다.
4. 사진이 있어야 분류와 AI 분석을 할 수 있습니다.

화면 05   사진·도면 관리 → 사진 탭. 가운데로 끌어다 놓거나 + 사진 추가로 올립니다.

화면 06   가져오기 완료 안내 — 확인을 누르면 사진 목록에 채워집니다.

사진 그룹 만들기
1. 왼쪽 패널(또는 홈 가이드)에서 + 새 사진 그룹을 누릅니다.
2. '이미지 그룹 생성' 창에서 그룹 이름을 입력하고 새 사진 그룹 버튼을 누릅니다.
3. 만든 그룹은 왼쪽 패널 사진 그룹 목록에 나타납니다.
4. 사진을 그룹으로 옮기면 보고서가 그룹 단위로 정리되고, 도면 배치도 쉬워집니다.

화면 07   이미지 그룹 생성 창 — 그룹 이름을 입력하고 새 사진 그룹을 만듭니다.

AI 분석
1. 홈에서 AI 분석하기를 누르거나, 사진·도면 관리에서 그룹을 골라 시작합니다.
2. AI 가 사진 속 손상을 찾아 손상물량표를 자동으로 채웁니다.
3. 상단 진행 표시줄에서 진척(예: 5/5)과 분석 중인 파일을 확인합니다.
4. 분석이 끝나면 사진에 초록색 분석 완료 표시가 붙습니다.

도면에 사진 그룹 배치 — 외관조사망도 (선택)

도면을 등록하고 그 위에 점검 위치를 찍어 사진 그룹을 연결합니다. 도면이 없어도 빈 도면으로 먼저 시작
할 수 있습니다.
도면 추가
1. 사진·도면 관리의 도면 탭에서 + 도면 추가(또는 좌측 + 새 도면 추가)를 누릅니다.
2. 도면 시작 방법 선택 — 도면 파일 넣기(PDF· DXF· JPG· PNG 지원) 또는 빈 화면으로 시작(위치만 먼저
찍고 나중에 파일로 교체).
3. 도면이 속한 시설물을 고르고 도면 이름을 입력한 뒤 저장을 누릅니다.

화면 10   사진·도면 관리 → 도면 탭. 처음에는 도면이 없습니다.

위치에 사진 연결 · 메모
1. 도면 위 위치 핀을 누르고 팝업에서 상세 보기를 엽니다.

4. 손상 탭에서 그 위치에서 찾은 손상 목록(종류·크기·출처 사진)을 확인합니다.

결과 파일 내용

가능)
손상물량표  (Excel) 손상 종류와 수량을 표로 정리
외관조사망도  (DXF) 도면에 위치·사진·손상물량표를 그려 산출
