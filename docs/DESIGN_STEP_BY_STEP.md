# KO-Detect — Step-by-Step 설계 문서

> 사진 한 장이 **법적 근거를 갖춘 처방**이 되어 **실제로 고쳐졌는지 확인**되기까지의
> 전 과정을 단계별로 기술합니다. 각 단계마다 **입력 · 처리 · 출력 · 완료기준(DoD) ·
> 현재 상태**를 명시했습니다.
>
> 근거 문서: BHC-STD-2026:0.9 (건축물 건강검진 표준) · 건축물 안전진단 AI 솔루션
> 도메인·기능 총정리(F1~F9) · 시설물안전법 · KDS 14 20 30

---

## 0. 설계 원칙 — 왜 이렇게 나누었는가

| 원칙 | 내용 | 코드상 반영 |
|---|---|---|
| **판정과 배관의 분리** | 법령 근거로 검증돼야 하는 판정 기준은 코드로 고정하고, 자주 바뀌는 수집·스케줄·통합은 워크플로우로 뺀다 | `backend/app/{domain,grading,bhc}.py` ↔ `n8n/workflows/` |
| **기준은 한 곳에** | 지침이 개정되면 고칠 파일이 하나여야 한다 | 모든 임계값이 `domain.py` · `bhc.py` 상수 |
| **모르는 것은 모른다고 한다** | 자동 판정 불가 항목을 채운 척하지 않는다 | 적신호 RF-3~RF-8은 수동 입력, 미실시 계통은 D3 처리 후 명시 |
| **환각 불가능한 문장 생성** | "환각 0건"은 확률적 생성으로 보장할 수 없다 | `opinion.py` 템플릿 조립 + 금지표현 검사기 |
| **폐루프** | 사고는 "몰라서"가 아니라 "알았는데 안 닫혀서" 난다 | CAPA 6상태 + 에스컬레이션 E1~E4 |

## Step 1. 촬영 — 스케일이 없으면 진단이 성립하지 않는다

| 항목 | 내용 |
|---|---|
| **입력** | 드론/현장 사진 + 촬영 메타 (거리, 짐벌각, 부재코드) |
| **처리** | 파일명 규약 파싱 → 메타 검증 → 규약 위반은 격리 큐 |
| **출력** | 검증된 사진 + `mm/px` 스케일 |
| **DoD** | 스케일 미확정 사진이 판정 경로로 들어가지 않을 것 |
| **상태** | ✅ `n8n/workflows/01_data_collection.json` · `routers/detect.py` |

```
파일명 규약: <시설물ID>_<부재코드>_<촬영거리m>_<YYYYMMDD-HHMM>.jpg
예)          1_column_8.0_20260830-0930.jpg
```

**왜 격리하는가** — 균열폭을 mm로 환산할 수 없으면 D등급 판정 자체가 성립하지
않습니다. 스케일 없는 사진은 "폭 미상"이 아니라 **판정 불가**입니다.

**GSD 산정** `GSD = (거리 × 센서폭) / (초점거리 × 이미지폭)`, 짐벌이 벽면에
수직이 아니면 `1/cos θ` 보정 (70° 이상은 신뢰 불가로 고정).

## Step 2. 검출 — 선형 구조만 남긴다

| 항목 | 내용 |
|---|---|
| **입력** | 사진 + `mm/px` |
| **처리** | 7단계 파이프라인 (아래) |
| **출력** | 균열 인스턴스 목록 (bbox · 중심선 · 폭 · 길이 · 신뢰도) |
| **DoD** | F1 mAP@0.5 ≥ 0.70 / F2 폭오차 ±0.3mm |
| **상태** | ⚠️ F1 0.689(근접 미달) · 폭 MAE **0.230mm (DoD 달성)** · 정밀도 0.800 (달성) |

```
① CLAHE 국소 대비 보정
② 다중 스케일 헤시안 능선 필터        ← 얼룩·골재는 선형이 아니므로 여기서 탈락
③ 암부 영역 내 Otsu + 히스테리시스     ← 전역 분위수는 "상위 N%" 고정 예산을 만들어
                                        뚜렷한 균열 하나가 나머지를 잡아먹는다
④ 연결요소 분석                        ← 길이·세장비·충실도·국소대비·사행도
                                        사행도 필터가 거푸집 이음선을 걸러낸다
⑤ 중심선 법선 방향 FWHM 폭 측정        ← 이진화 임계에 좌우되지 않는 폭 정의
⑥ 촬영계 PSF 이차합 보정               ← 흐림이 균열을 넓어 보이게 하는 계통오차 제거
⑦ GSD 적용 + 선명도 게이트             ← 흐리면 재촬영 권고, 측정값을 신뢰하지 않는다
```

**개선 이력 (4회 진단)**

| # | 발견한 문제 | 조치 | 효과 |
|---|---|---|---|
| 1 | 정답 라벨이 명목 선두께 | 렌더링 마스크에서 동일 정의로 재측정 | 편향의 원인 제거 |
| 2 | 성장 영역이 선형 제약 없이 확산 | 능선 응답으로 제약 | 재현율 0.20 → 0.48 |
| 3 | 폭 정의가 이진화 임계 의존 | FWHM + PSF 보정 | 편향 +0.72 → −0.12mm |
| 4 | bbox IoU 매칭이 무너짐 | 중심선 버퍼 겹침으로 교체 | 지표 신뢰성 확보 |
| 5 | 팽창 병합이 별개 균열을 뭉침 | **방향 인지 파편 연결** | 재현율 0.556 → 0.662 |
| 6 | 분기점에서 폭이 튐 | **MAD 이상치 제거** | MAE 0.506 → 0.375mm |
| 7 | 형상 규칙의 가중치에 근거가 없음 | **합성 GT로 분류기 학습** (AUC 0.958) | 정밀도 0.400 → 0.800 |
| 8 | MAD 도입 후 PSF가 과보정 | **PSF 2.6 → 2.2 재보정** | 편향 −0.279 → −0.011mm |

**최종** — 동일 테스트셋 120장에서 F1 0.499 → **0.689**, 정밀도 0.400 → **0.800**,
폭 MAE 0.375 → **0.230mm**, 편향 −0.279 → **−0.011mm**.

> **남은 문제는 재현율(0.605)입니다.** 놓친 균열은 대부분 배경 대비가 낮아 분할
> 단계에서 후보 자체가 만들어지지 않습니다. 분류기는 만들어진 후보 중에서만
> 고르므로 이 손실을 회복할 수 없습니다. 학습 모델(Mask R-CNN + Y-MaskNet)
> 전환이 정공법이며, `CrackDetector.detect()` 시그니처를 고정해 두었습니다.

## Step 3. 심각도 판정 — 두 체계를 동시에 유지한다

| 항목 | 내용 |
|---|---|
| **입력** | 결함 유형 · 측정값 · 노출환경 |
| **처리** | 법정 상태등급(a~e) + 표준 심각도(D1~D5) 병행 산정 |
| **출력** | 등급 · 판정근거 문자열 |
| **DoD** | 기준 개정 시 상수 파일 한 곳만 수정 |
| **상태** | ✅ `grading.py`(법정) · `bhc.py`(표준) |

**두 체계를 왜 같이 두는가** — 세부지침 상태평가(a~e)와 BHC 표준 심각도(D1~D5)는
임계값이 다릅니다. 법정 보고서에는 전자를, 건강검진 소견서에는 후자를 씁니다.
하나로 합치면 둘 중 하나가 틀립니다.

| 균열폭 | 법정 a~e | BHC D1~D5 |
|---|:---:|:---:|
| < 0.1mm | a 우수 | D1 정상 |
| 0.1 ~ 0.2 | b 양호 | D2 관찰 |
| 0.2 ~ 0.3 | c 보통 | D2 관찰 |
| 0.3 ~ 0.5 | d 미흡 | D3 주의 |
| 0.5 ~ 1.0 | d 미흡 | D4 위험 |
| ≥ 1.0mm | e 불량 | D5 긴급 |

**환경 보정** — 표준 §8.1의 폭 기준은 보통 노출환경 전제입니다. 부식성 환경에서는
허용균열폭 비로 폭을 환산해 더 엄격하게 판정합니다.

```python
effective = width_mm × (습윤환경 허용폭 / 해당환경 허용폭)
# 고부식성(0.10mm) 환경의 0.30mm 균열 → 유효 0.90mm → D4
```

## Step 4. 확산도 보정 — 1개소와 전면은 다르다

$$s' = 100 - (100 - s)(0.5 + 0.5\rho), \qquad \rho = \frac{\text{결함 발현 부재 수}}{\text{조사 동종 부재 수}}$$

국부 결함(ρ→0)은 감점의 절반만, 전면 결함(ρ=1)은 전량 반영됩니다.
**D5에는 적용하지 않습니다** — 붕괴 위험은 1개소만으로 성립하기 때문입니다.

> ⚠️ **현재 한계** — 데이터 모델이 "조사한 동종 부재 수"를 기록하지 않아, 운용
> 가정값(기본 10)으로 분모를 둡니다. API 응답의 `assumptions` 에 이 사실을 함께
> 내보냅니다. 표본계획이 도입되면 `Inspection` 에 실제 조사 부재 수를 저장해
> 대체해야 합니다.

## Step 5. 계통 점수 → BHI

| 항목 | 내용 |
|---|---|
| **처리** | 부재 중요도 v(1/2/3) 가중평균 → 계통점수 → 가중합 |
| **출력** | S1~S6 점수 + BHI (0~100) |
| **상태** | ✅ `bhc.system_scores()` · `assess_checkup()` |

$$S_i = \frac{\sum_k v_k s'_k}{\sum_k v_k}, \qquad \mathrm{BHI} = \sum_{i=1}^{6} w_i S_i$$

| 계통 | 인체 대응 | 가중치 | 하한 |
|---|---|---:|---:|
| S1 구조 | 골격계 | 0.32 | 0.30 |
| S2 외피 | 피부계 | 0.14 | — |
| S3 순환 | 순환계 | 0.12 | — |
| S4 방호 | 신경·면역계 | 0.24 | 0.20 |
| S5 대사 | 대사계 | 0.06 | — |
| S6 이력 | 문진·병력 | 0.12 | — |

**두 가지 강제 규칙**
- 계통 내 D5가 1건이라도 있으면 **계통점수 상한 30점**
- 미실시 계통은 **65점(D3 상당)** 으로 처리하고 소견서에 명시

## Step 6. 적신호 — 가중합이 치명 결함을 희석하는 것을 막는다

가중합은 국지적 치명 결함을 평균에 묻습니다. BHI 산정 **이후** 강제 적용하며,
복수 조건이면 가장 낮은 상한을 취합니다.

| 코드 | 조건 | BHI 상한 | 자동판정 |
|---|---|---:|:---:|
| RF-1 | 어느 계통에서든 D5 1건 이상 | 39.9 → E | ✅ |
| RF-2 | S1 구조계통 D4 1건 이상 | 59.9 → D | ✅ |
| RF-3 | 소방 주요설비 기능정지·임의차단 | 49.9 → E | 수동 |
| RF-4 | 피난동선 폐쇄·잠금·적치 | 49.9 → E | 수동 |
| RF-5 | 방화구획 결함 30% 이상 | 59.9 → D | 수동 |
| RF-6 | 구조검토 없는 내력벽 제거 | 59.9 → D | 수동 |
| RF-7 | 직전 P0 처방 기한 초과 미이행 | 64.9 → C | ✅(CAPA 연동) |
| RF-8 | 가연성 외장재 + 피난·소방 결함 | 49.9 → E | 수동 |

**영상으로 판정할 수 없는 것을 판정한 척하지 않습니다.** RF-3~RF-6·RF-8은
점검자가 현장에서 확인해 입력합니다. 적신호가 발동하면 소견서 1면에 **규칙 번호와
근거 결함코드를 반드시 병기**합니다(미기재 시 표준 미준수).

**실측 예시** — 서울 공공임대 A동: BHI 74.7점(C 상당)이었으나 D5 결함 15건으로
RF-1이 발동, **39.9점 E등급**으로 강제. 가중합만 봤다면 C로 판정될 사안입니다.

## Step 7. 건강나이 · 열화속도

$$\mathrm{BHA} = \frac{100 - \mathrm{BHI}}{\beta}, \quad \Delta = \mathrm{BHA} - t_{\text{실제}}, \quad v = \frac{\mathrm{BHI}_{\text{직전}} - \mathrm{BHI}_{\text{금회}}}{\Delta t}$$

| 코호트 | β (점/년) |
|---|---:|
| RC 공동주택 | 1.2 |
| 업무·근린생활 | 1.1 |
| 학교·공공청사 | 1.3 |
| 조적조·무근 | 2.0 |
| 개방주차장·외기노출 | 1.7 |

| Δ | 판정 |
|---|---|
| ≤ −5년 | 건강노화 |
| −5 ~ +5년 | 정상노화 |
| ≥ +5년 | 가속노화 — 원인 규명 |
| ≥ +10년 | 조기노화 경보 — L2 승급 권고 |

> **건강나이는 참고지표입니다.** β가 잠정값이고 코호트 표본이 30건에 미달하므로,
> 등급 판정이나 처방 우선순위 결정에 사용하지 않습니다(§8.7). 소견서에 이 사실을
> 함께 적습니다.

**설계상 발견한 함정** — §8.8은 BHI(적신호 적용 후)로 v를 정의하는데, 두 회차가
같은 적신호 상한에 걸리면 **v = 0 "개선"** 으로 나와 실제 악화가 가려집니다.
표준 규범값은 그대로 두고, **상한 적용 전 BHI로 산출한 보조지표**를 병기해
`rate.saturated` 플래그로 포화 여부를 알립니다.

## Step 8. 소견 문장 — 관측 · 해석 · 권고를 섞지 않는다

| 요소 | 규칙 | 예시 |
|---|---|---|
| **관측** | 측정값과 사실만 | "3층 서측 기둥 C-7에 균열 · 최대폭 0.62mm(±0.02) · 동종 부재 25%에서 발현 관측." |
| **해석** | 기준과 대조 | "D4(위험)에 해당한다. 습윤환경의 허용균열폭 0.30mm(KDS 14 20 30)를 0.32mm 초과한다. 주요부재에서 발생하여 계통 건강점수에 지배적으로 작용한다." |
| **권고** | 조치와 기한 | "P1(긴급). 2026-09-29까지 단면복구 및 방청처리, 시공 전 철근 부식도 확인." |

**금지표현 검사기** — 표준 §9.2가 금지한 4개 범주를 정규식으로 검출합니다.
사람이 직접 쓴 소견에도 적용할 수 있습니다 (`POST /api/bhc/lint`).

| 범주 | 예 | 대체 |
|---|---|---|
| 측정값 없는 형용 | "다수의", "심각한" | 개소 수·비율·측정치 |
| 근거 없는 단정 | "붕괴 위험이 있음", "안전에 이상 없음" | 관측 사실 + 심각도 등급 |
| 책임 회피형 | "관리주체의 판단이 필요함"만 기재 | 조치·기한 명시 |
| 원인 단정 | "노후화에 의한" | "원인 미상, 추가 조사 필요" |

**왜 LLM이 아닌가** — F3의 완료기준은 "기술용어 환각 0건"입니다. 생성형 모델은
확률적이라 0건을 보장할 수 없고, 검증하려면 결국 사람이 전수 확인해야 합니다.
측정값과 판정근거가 이미 구조화되어 있으므로 템플릿 조립이면 **환각이 원리적으로
불가능**하고 문장 구조도 항상 표준을 지킵니다. 생성형 모델은 이 초안을 다듬는
후단 옵션으로 둡니다.

## Step 9. 처방 — 심각도가 우선순위를 결정한다

| 우선순위 | 발동 요건 | 기한 | 통보 |
|---|---|---|---|
| **P0** 응급 | D5 · RF-1·3·4 | 즉시 응급조치, 24h 내 착수 | 구두 후 당일 서면 |
| **P1** 긴급 | D4 · RF-2·5·6·8 | 30일 | 소견서 별도 표지 |
| **P2** 계획보수 | D3 | 90일 | 소견서 |
| **P3** 중장기 | D3 중 대규모 | 1년 (장기수선계획) | 소견서 연계 |
| **P4** 추적관찰 | D2 | 차기 검진 | 소견서 |

> **P0는 소견서 완성 여부와 무관하게 즉시 통보**해야 합니다. 소견서 작성을 이유로
> 지연하면 표준 위반입니다. 시스템은 P0가 있으면 1면 요약 주의사항에 이 조항을
> 자동으로 넣습니다.

## Step 10. CAPA 폐루프 — 표준의 핵심

```
발행 ─7일─▶ 접수 ──▶ 계획 ──▶ 이행 ──▶ 검증 ──▶ 종결
  │           │        │        │        │
  └───────────┴────────┴────────┴────────┘
              에스컬레이션 (기한 초과)  ──▶ 강제조치
                                검증 부적정 시 → 계획으로 되돌림
```

**이행(Executed)만으로는 종결되지 않습니다.** 검증(Verified)을 거치지 않은 처방은
다음 검진에서 미이행으로 계상됩니다. 이 조항이 *"보수했다고 보고했으나 실제로는
덮기만 한"* 사례를 차단합니다.

| 단계 | 발동 | 조치 |
|---|---|---|
| E1 | 기한 초과 1일 | 담당자·관리책임자 자동 통지 |
| E2 | 초과 15일 또는 P0 24h 초과 | 대표 서면 통지 · 사유서 요구 |
| E3 | 초과 30일 | 차기 검진 S6에 D4 계상 · RF-7 검토 |
| E4 | P0 7일 초과 미착수 | 관계기관 통보 검토 · 사용제한 권고 |

**성과 지표** — 폐루프 종결률 · 기한 준수율 · 평균 종결 소요일 · 재발률 ·
검증 부적정률. 재발률 15% 초과 결함 유형은 **보수 공법 자체를 재검토**합니다.

> ⚠️ **현재 상태** — 이행·검증 기록 테이블이 아직 없어 모든 처방을 '발행'으로 봅니다.
> `on_time_rate`·`overdue`·에스컬레이션 단계는 산출되고, `closure_rate`는 0입니다.
> 다음 작업은 `Prescription` 테이블과 상태 전이 API입니다.

## Step 11. 실시간 계측 · MTM

점검은 수개월 주기로만 갱신됩니다. 그 사이의 변화는 상시 계측이 메웁니다.

$$\text{건전성} = 100 \times \bigl(1 - [(1-w)\cdot \text{결함도} + w \cdot \text{계측스트레스}]\bigr)$$

계측 스트레스는 **최악 채널이 지배**(0.7)하고 평균이 보조(0.3)합니다 — 단일 채널
이상을 평균에 묻지 않기 위함입니다. 화면은 TradingView 캔들로 표시합니다.
구간 고가–저가 폭이 곧 구조 응답의 진폭이므로 선보다 정보량이 많습니다.

## Step 12. 유지관리 정책 — 강화학습

예산 제약 하의 점검·보수를 **POMDP**로 봅니다. 부재의 실제 열화 등급은 볼 수 없고,
점검해야만 잡음 섞인 관측을 얻습니다.

| 기법 | 채택 이유 |
|---|---|
| Branching Dueling | 부재 N개 × 5행동의 결합공간 5^N을 선형(N×5)으로 축소 |
| 분포형 C51 + **CVaR** | 안전 문제는 기댓값이 아니라 꼬리가 중요. 하위 35% 조건부 기댓값 최대화 |
| NoisyNet | 예산 제약 장기 문제에서 ε-greedy보다 일관된 탐색 |
| PER + n-step | 드물게 발생하는 심각 열화 전이를 우선 학습 |

기준정책 대비 (30년·6부재·연 4천만원): 사후보수 −2.66 / 정기보수 39.32.

> ⚠️ 열화 전이확률·보수비용은 **가정치**입니다. 실제 유지관리 이력으로 재추정해야
> 정책이 의미를 갖습니다. 현재는 구조와 학습 파이프라인 동작 확인 단계입니다.
